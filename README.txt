# FIXAM Website

This is an editable static website for FIXAM.

## Files

- index.html — website structure and text
- style.css — colors, layout, spacing, and responsive design
- script.js — mobile navigation, current year, and email enquiry form

## How to edit

1. Extract the ZIP file.
2. Open the files using a code editor such as Visual Studio Code or Notepad.
3. Edit the text in `index.html`.
4. Edit the colors and layout in `style.css`.
5. Open `index.html` in a browser to preview the website.
